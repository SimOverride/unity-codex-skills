# 可调资产

## 适用情况

- 同一基础资产需要多个高度、宽度或比例版本。
- 液面、提手、机械部件位置需要制作阶段调节。
- 用户需要在确认外观后再烘焙并导出。

## 控制方式

优先级：

1. 几何节点或修改器参数。
2. 自定义属性驱动。
3. 控制 Empty 或骨骼。
4. 重新运行确定性生成脚本。

不要通过大量手动顶点编辑维持多个版本。

## 控制要求

- 使用一个清楚命名的控制对象集中暴露参数。
- 参数写明单位、默认值和安全范围。
- 相关部件联动。例如桶高度改变时，桶口、提手固定点和液面上下限同步。
- 验证最小值、默认值和最大值。
- 不让负缩放、翻面、零厚度或自相交成为可调结果。

## Unity 边界

Blender 驱动和自定义属性通常不会成为 Unity Inspector 滑块。交付前明确：

- 参数只用于制作变体：烘焙后导出 FBX。
- 参数需要在 Unity 运行时变化：导出足够的网格、骨骼或 Blend Shape，再由 Unity 代码驱动。
- 简单高度变化可以使用独立液面对象的位置，而不是实时重建模型。
