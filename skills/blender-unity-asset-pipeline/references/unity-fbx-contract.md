# Unity FBX 合同

## 单位与坐标

- 先确认 Blender 场景单位和资产真实尺寸。
- 默认姿态应能在 Unity 中直接使用，不依赖导入后补 90 度旋转。
- 记录模型正面方向、上方向和根节点位置。
- 对需要旋转的对象验证轴心世界位置与局部轴方向。

## 导出内容

只导出目标资产：

- 目标 Mesh。
- 必要 Armature。
- 必要 Empty 或骨骼。
- 必要动画。

排除预览相机、灯光、地面、尺寸标注、控制辅助和临时高模。

## 网格

- 固化决定性的三角拓扑。
- 按需求应用修改器；不要把 Unity 不支持的修改器留在结果中。
- 写入需要的平滑法线、切线、UV 和顶点色。
- 记录材质槽顺序，避免重导入时子网格含义变化。

## 动画

- 只导出需要的 Action 或 NLA 片段。
- 检查是否误导出全部动作、空动作或临时动作。
- 确认采样率、帧范围和根运动。

## 回读验收

把 FBX 导入空 Blender 场景后检查：

1. 总尺寸和位置。
2. 默认朝向与姿态。
3. 对象数量和名称。
4. 材质槽与子网格。
5. UV、法线和三角形数量。
6. 轴心和父子关系。
7. 骨骼数量、蒙皮和动画片段。

随后在 Unity 中检查 Importer。Blender 回读通过不能代替 Unity 导入验证。
