# 静态道具

## 结构

- 根据 Unity 中独立移动、旋转、换色和隐藏需求拆分对象。
- 不因 Blender 编辑方便而保留 Unity 不需要的碎片对象。
- 旋转部件的轴心放在真实机械连接处。
- 纯色道具用少量稳定材质槽；不要把参考图中的描边误做成侧面材质。

## 几何

- 先保证剪影和主要体块，再增加倒角和结构线。
- 平整板面保持共面，避免非平面五边以上多边形产生不可控三角化。
- 明确最终三角拓扑；FBX 导出前不要把关键三角化交给不同导入器决定。
- 删除封闭道具内部不可见且无用途的面。
- 钉子、螺栓和圆柱使用与屏幕尺寸相符的边数。

## 材质与换色

- Unity 需要独立换色的部分使用独立材质槽或独立 Renderer。
- 同一材质的实例换色优先由 Unity `MaterialPropertyBlock` 完成。
- 固定颜色部件不要与运行时换色部件共享材质槽。

## 轴心示例

- 挂锁锁梁：轴心位于连接侧旋转中心。
- 门、箱盖：轴心位于铰链。
- 桶提手：如果需要摆动，轴心位于两侧固定点或使用骨骼。
- 钥匙：轴心与插入和旋转动画的握持方向一致。
