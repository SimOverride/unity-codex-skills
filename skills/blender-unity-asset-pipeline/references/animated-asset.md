# 动画资产

## 结构选择

- 刚体机械部件：优先骨骼或独立对象父子层级，不必强制蒙皮。
- 角色和柔性变形：使用骨骼与蒙皮。
- Unity 只需代码 Tween 的简单开合：提供正确对象拆分和轴心即可，不必制作动画片段。

## 骨骼

- 骨骼命名稳定且能表达部位。
- Rest Pose 是资产的默认可用姿态。
- 根骨骼负责整体位移；局部骨骼不混入意外全局位移。
- 蒙皮权重不跨越无关刚体部件。
- 检查镜像、负缩放和应用变换对骨骼的影响。

## Action

每个动画明确：

- 名称。
- 起止帧。
- 是否循环。
- 默认速度。
- 是否包含根运动。
- 开始与结束姿态。

常见片段包括待机、移动、攻击、受击、死亡、展开、收起和瞄准。只制作用户需要的集合。

## 默认姿态

- 保存文件和导出前取消临时 Action 或恢复指定默认 Action 的起始帧。
- 清除未烘焙的临时 Pose。
- 重新打开 `.blend` 和回读 FBX，确认资产不是停在死亡、倒地或展开末帧。

## Unity 检查

- Rig 类型与资产匹配。
- Animation Clip 名称和帧范围正确。
- 循环片段启用正确的 Loop 设置。
- 根运动按项目规则启用或禁用。
- 无额外 Preview 相机、灯光、控制骨或辅助网格混入。
