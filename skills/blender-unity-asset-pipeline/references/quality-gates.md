# 资产质量门槛

## 几何

- 无意外重合点、重复面和共面叠面。
- 无退化面、零长度边和孤立顶点。
- 封闭实体没有非流形边；有意开放模型需记录原因。
- 无不可见且无用途的内部面。
- 平面与硬边法线稳定。
- 修改器结果在导出状态下可预测。

## 性能

- 三角形数量符合用户、项目或屏幕尺寸预算。
- 材质槽数量与实际换色、透明和渲染需求一致。
- 不使用几何表达可以由纹理或 Shader 低成本完成的微小细节。
- 骨骼、权重、Action 和纹理分辨率不过度。

## Unity 结构

- 独立动画部件可单独访问。
- 轴心与动画动作一致。
- 默认姿态正确。
- 材质槽顺序稳定。
- UV 接缝与滚动方向符合使用场景。
- FBX 中没有预览对象和制作辅助。

## 视觉

- 从主要游戏镜头检查剪影、厚度和结构比例。
- 用纯色检查材质检查法线和明暗条纹。
- 用描边或投影检查轮廓连续性。
- 有纹理时检查接缝、翻转、密度和边界循环。
