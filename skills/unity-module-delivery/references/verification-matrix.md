# Unity 交付验证矩阵

| 修改类型 | 最低验证 | 补充验证 |
|---|---|---|
| 纯 C# 规则 | 编译、针对性单元测试、边界值 | 随机序列、幂等、序列化往返 |
| MonoBehaviour | 编译、生命周期审查 | EditMode、PlayMode、禁用/启用、场景重载 |
| 事件系统 | 订阅对称、重复注册检查 | 对象销毁、池化重用、异常中断 |
| Tween/协程 | 完成、中断、禁用、销毁路径 | 连续触发、队列、时间缩放 |
| 对象池 | 获取、回收、池满、异常路径 | 热重载、场景退出、残留对象 |
| UI | 初始刷新、事件刷新、坐标转换 | 多分辨率、Canvas 模式、禁用重开 |
| Prefab/场景 | 序列化引用、缺失引用、GUID | Unity 重导入、实例覆盖、Prefab Mode |
| ScriptableObject | 默认值、旧资产加载 | 迁移、共享数据副作用 |
| 编辑器工具 | 编译、Undo、脏标记、保存 | 多选、Prefab Stage、域重载 |
| 网络/确定性 | 指令排序、重复、乱序 | 丢包、迟到、回滚、状态哈希 |
| 文档 | 当前行为与配置一致 | 设计文档实现标识扫描 |

## 通用收尾

- 运行实际可用的编译或测试命令。
- 运行 `git diff --check`。
- 检查没有覆盖用户无关改动。
- 检查代码行尾符合项目规则。
- 存在 `.codegraph/` 时更新索引。
- 明确自动验证与人工验证的边界。
