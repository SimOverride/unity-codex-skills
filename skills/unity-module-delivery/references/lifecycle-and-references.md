# 生命周期与引用

## 生命周期职责

- `Awake`：初始化自身数据，获取当前物体或确定父子层级组件，创建不依赖其他 MonoBehaviour 已初始化的内部对象。
- `OnEnable`：注册事件、启动可重复启用逻辑；不假设其他对象已经执行 `Awake`、`OnEnable` 或 `Start`。
- `OnDisable`：对称取消注册，停止当前启用周期创建的协程、Tween 或回调。
- `Start`：执行依赖其他对象已完成 `Awake`/`OnEnable` 的场景级接入和初始刷新。
- 显式初始化：用于需要确定顺序、可测试、可重复构建或网络重建的复杂模块。

## 引用分类

| 引用 | 默认处理 |
|---|---|
| 当前脚本所在物体的组件 | `Awake` 中 `GetComponent` |
| 确定的父物体或子物体组件 | `Awake` 中按稳定层级获取 |
| 场景中的摄像机、管理器或其他外部物体 | `[SerializeField] private` 手动配置 |
| Prefab、材质、音效、纹理等项目资源 | `[SerializeField] private` 手动配置 |
| 运行时生成对象 | 由创建者显式传入或绑定 |

项目 `AGENTS.md` 有不同规则时，以项目规则为准。

## 检查问题

1. 组件在禁用、销毁、回收或热重载时是否仍可能收到回调？
2. 事件源是否在注册前已经确定？
3. Tween、协程、异步任务是否能在对象禁用时安全取消？
4. 对象池重用时是否重置全部运行时状态？
5. 自动获取失败时是否给出清楚错误，而不是静默降级？
6. 最终交付是否区分手动配置与自动获取？
