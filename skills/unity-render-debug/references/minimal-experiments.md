# 最小隔离实验

## 规则

1. 保存基线截图和当前参数。
2. 每次只改变一个变量。
3. 用临时材质、复制 Prefab 或独立测试场景，避免污染正式资源。
4. 记录“改变什么、现象如何、排除了什么”。
5. 实验结束后恢复临时设置。

## 光照拆分

按顺序单独显示：

1. Base Color。
2. 环境光。
3. 漫反射。
4. 高光。
5. 阴影衰减。
6. 法线贴图。
7. 最终合成。

哪个阶段首次出现异常，根因通常位于该阶段或其输入。

## 阴影拆分

组合测试：

| Cast | Receive/阴影衰减 | 含义 |
|---|---|---|
| 关 | 关 | 无实时阴影基线 |
| 开 | 关 | 只观察该物体向其他表面投影 |
| 关 | 开 | 只观察其他物体对它的投影 |
| 开 | 开 | 包含自阴影与完整交互 |

自定义 Shader 的 Receive Shadows 可能不是 Renderer 开关自动控制，必须读代码确认。

## 描边拆分

分别可视化：

- 原始对象颜色。
- 源遮罩。
- 需要封口的附加遮罩。
- 扩张后遮罩。
- 原始遮罩扣除。
- 排除遮罩。
- 最终轮廓。

不要直接观察最终黑线猜测是哪一步错误。

## 模型拆分

- 使用统一纯色 Unlit。
- 使用面法线颜色或法线调试 Shader。
- 禁用法线贴图。
- 比较导入法线与 Unity 重算法线。
- 禁用模型压缩。
- 检查单个三角形和主要平面。

## 透明拆分

- 临时改 Opaque。
- 分别测试 ZWrite On/Off。
- 把前后对象分开，消除相交。
- 固定 Render Queue。
- 比较按对象排序与拆网格排序结果。
