# 月度复盘与 Skill 维护流程

## 目标

每月从真实 Codex 对话中识别：

- 重复执行的工作流。
- 已有 Skill 的命中与未命中。
- 反复出现的漏项、返工和失败。
- 应新建、更新、继续观察或不适合封装的内容。

复盘关注流程是否复用，不按某个具体功能出现次数机械统计。

## 运行节奏

### 每周轻量索引

建议每周五记录一次任务索引，不修改 Skill。

索引字段：

- 日期。
- 项目。
- 用户目标。
- 工作类型。
- 使用的 Skill。
- 交付物。
- 是否返工。
- 返工原因。
- 未解决问题。

如果 Codex 能直接读取任务历史，可以省略手工索引；月度任务仍需读取代表性实际对话。

### 月末完整复盘

建议每月最后一天 20:00 运行，只生成报告。

范围使用完整自然月，例如 8 月任务读取 `2026-08-01 00:00` 至 `2026-08-31 23:59`。

输出保存为：

```text
docs/reviews/YYYY-MM.md
```

### 月初更新评估

建议次月第一天 10:00 读取最新报告，形成 Skill 更新建议。

默认只输出建议和拟修改范围。真正修改需要满足证据门槛，并由使用者确认。

## 月末复盘步骤

### 1. 采集任务

读取任务标题、用户消息、重要澄清、最终结果、文件变更、验证结果和未完成事项。不能只根据标题或自动摘要判断。

记录失败、回退和用户纠正，因为它们最能说明 Skill 缺少什么。

### 2. 分类

为任务添加：

- 项目。
- 领域。
- 工作类型：规划、实现、诊断、研究、建模、文档、数据采集或发布。
- 输入类型。
- 输出类型。
- 使用的 Skill。
- 完成、部分完成、阻塞或回退。
- 自动验证与人工验证。

### 3. 识别重复工作流

工作流需要满足：

1. 至少在两个不同真实任务中出现。
2. 输入与目标具有共同结构。
3. 核心步骤和验收相对稳定。
4. 封装后能减少遗漏、返工或重复代码。
5. 能说明何时不应触发。

只因主题相似，不代表工作流相同。

### 4. 评分

每项按 1 至 5 分评分：

| 维度 | 判断 |
|---|---|
| 频率 | 是否在多个任务或项目中重复 |
| 稳定性 | 步骤、输入输出和验收是否稳定 |
| 出错成本 | 漏项是否会造成返工、数据损坏或错误交付 |
| 可沉淀资源 | 是否能形成脚本、参考资料或资产 |
| 独立性 | 是否有清晰触发条件，且不与现有 Skill 重叠 |

总分用于排序，不代替边界判断。

### 5. 分类决策

#### 建议新建 Skill

- 工作流边界独立。
- 在不同任务中重复。
- 通用模型知识不足以稳定完成。
- 有清晰触发与非触发条件。

#### 建议更新 Skill

- 已有 Skill 已经命中，但至少两个真实案例暴露同一漏项。
- 新规则属于该 Skill 的长期职责。
- 修改可以删除失效内容，不需要堆叠兼容规则。

#### 继续观察

- 只有一个案例。
- 工作流正在变化。
- 尚不清楚应写成参考资料还是脚本。

#### 不适合 Skill

- 单项目约束：写入项目 `AGENTS.md`。
- 确定性批处理：优先项目脚本。
- 一次性知识问答：不封装。
- 已有 Skill 可以覆盖：改进现有 Skill 或直接复用。

## Skill 更新步骤

1. 收集原始案例，不只使用月报结论。
2. 使用 `skill-creator` 读取目标 Skill。
3. 明确修改解决的真实失败。
4. 修改最小必要范围。
5. 过时规则直接删除。
6. 详细内容放入一级 `references`。
7. 重复且确定的操作放入 `scripts`。
8. 实际运行新增或修改脚本。
9. 运行 `quick_validate.py`。
10. 用未泄漏预期答案的真实任务做前向测试。
11. 更新 `docs/CHANGELOG.md`。
12. 提交仓库，再同步个人安装目录。

## 月度报告结构

```markdown
# YYYY-MM Skill 复盘

## 本月范围
## 工作主线
## 已有 Skill 使用情况
## 重复工作流
## 失败、返工与用户纠正
## 建议新建 Skill
## 建议更新 Skill
## 继续观察
## 不适合 Skill 的内容
## 下月验证计划
```

## 安全边界

- 月末自动任务只读，不修改 Skill、项目或外部仓库。
- 月初任务默认只提出建议。
- 不从单个失败案例直接修改通用 Skill。
- 不把用户名、私有代码、凭据、完整对话或敏感业务数据写入月报。
- 发布前检查报告和 Skill 中是否包含本地绝对路径或项目秘密。
